##  Estrutura do Repositório

- **index.html** — Página principal que exibe o card de preços (price card).
- **estilo.css** — Folha de estilo que define o visual do card.
- **.gitattributes** — Configurações de controle de versão para Git.
- **LICENSE** — Licença MIT garantindo liberdade de uso e modificação.

---

##  Sobre o Projeto

O **Price-Card** é um componente simples, mas funcional, ideal para destacar planos ou ofertas em uma página web. O foco neste projeto foi:

- Estruturar o **HTML** de forma semântica e clara.
- Aplicar **CSS** para layout responsivo, tipografia legível e design atraente.
- Praticar posicionamentos com `flexbox` ou `grid`, estilização de botões e elementos destacados.
- Criar um cartão visualmente clean e personalizável.
